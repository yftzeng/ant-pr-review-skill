# ant-pr-review

多模型、跨厂商的**公关风险审查**工具，由 Claude skill（`SKILL.md`）加上独立的 Python CLI 组成。[English](README.md) · [繁體中文](README.zh-TW.md)

可以审查三种内容：
- **对外发布**：我方要发的内容（新闻稿、声明、帖子、广告、KOL 脚本）
- **操作计划**：散布或舆论操作计划
- **被攻击**：针对我方的内容（爆料、抹黑、差评潮）

每一种都会按法域（台湾、美国、欧盟、中国）分别评估白公关与黑公关的发布与操作风险。

- **每题都由每个模型作答的检查清单**：固定题目分属 10 个视角，另有各姿态与各角色专属题目：法务、敌意记者、网络社区、被指涉方、监管与平台、内部人、揭发者、威胁研判、回应策略。未作答的题目视为缺口，不算通过。
- **跨厂商**：可用方向键勾选 Claude（opus / sonnet / fable，经 `claude -p`）、OpenAI、Gemini、Grok、OpenRouter。全部来自同一家时仍可执行，但会醒目提示，因为同一厂商的模型盲点相近。
- **一个法域一组调用**：每个法域由各自的调用审查，不会一次处理多国。勾选多国时，会有一个独立的汇总模型比较各国结果、向各国审查者提问讨论，再生成汇总版报告与各国版报告。
- **两种深度**：`quick` 是每个模型一次，加上每个法域一次；`full` 是每个视角、每个法域各一次，调用数约为 quick 的 4 倍。
- **判定由程序计算**：风险登记表（可能性 × 冲击）、红线否决（对具名对象的捏造陈述、水军与未披露广告、人肉、选举法规、影响股价、疗效宣称、仇恨），最后给出可发布／有条件／送审／不可发布。
- **有伦理护栏的处置方案 A/B/C**：A 是最小安全修改（字符级 diff），B 是合法替代方案，C 是应变包。护栏会移除隐匿身份或规避追溯的建议、假冒网友的评论，以及只换说法的抹黑，并标示移除了什么。
- **姿态与手段**：姿态可选澄清道歉（默认）、广告造势、狙击爆料或回应抹黑，每种姿态都有自己的检查题；狙击爆料限我方具名，通过不具名第三方放料属于黑公关；手段可勾选白、灰、黑公关。不论勾选哪些手段，检查题一律从白、灰、黑三个角度审查；勾选结果只影响报告最后的手段时间轴。时间轴列出白、灰公关的执行步骤：相对时间、当地时刻、顺序、渠道、注意事项、触发与停止条件，并由另一家厂商的模型重新分类，以较严格的分类为准。黑公关一律不排入执行，只放进“已评估、不执行”表，说明涉及的法律、通常如何被揭穿、对手若对我方使用时的征兆，以及合法替代做法。
- **公司概况**：提供统一编号并经你同意后，会查询经济部商工登记的公司资料和营业项目（不保存代表人姓名和地址），并由可搜索的模型找出竞争对手。每家对手的来源都分 A/B/C 级，只有你勾选的才会纳入审查。
- **我方角色与利益相关方地图**：先选你在事件中的立场（涉事方、受害方、关系方），再选具体身份，例如公司本身、董事会、代言人、吹哨人；检查清单会加上该角色专属的题目。每个模型都会按法域，回答 7 大类（内部治理、商业链条、资本市场、公权力、政治与政党、舆论、博弈势力）各角色可能如何反应、需要什么、我方如何处理。侧翼水军和中国党政机构只评估、不能选为我方角色。另有 5 道角色压力测试（法律底线、群众情绪、内部防线、商业命脉、舆论弹药）和 3 道政治压力测试（弹药、极化夹杀、主权与合规红线），每道都要指出关键的那一句。
- **每个阶段都有人复审，每一题都是勾选清单**：A、B、C、时间轴和黑公关排除表，都由另一家厂商的模型复审。检核清单以勾选清单呈现，附 ASCII 通过率长条和每位审查者的判定。对外发布的内容还会附上修订前后的 diff 与修订后全文，并以 quick 深度重审修订版（列出修订前 → 修订后）。你锁定的句子不会被改动。
- **撰写模式**：不审已有内容，改为回答固定问答，内容包括：
  - 事实，分已确认、被指控、未知；
  - 事件类型；
  - 受影响的人和他们最强烈的情绪；
  - 想要的结果和要做的决定；
  - 措施和各自的进度；
  - 批准人；
  - 原因与范围是否已确认，尚未确认就只写等候声明；
  - 不可承认或承诺的事，例如召回；
  - 第四级标记，例如有人受伤或已进入诉讼。

  也可以附上材料用于核对事实。一个模型写两个做法不同的版本，另一个模型对照问答审查，每个版本再用同一套检查矩阵各审一次。排序由程序决定，依次看是否淘汰、判定、最高风险分数、通过率；再由模型引用这些数字写推荐理由。推荐的版本会走完整审查，最后附 diff 和修订后全文。每个说法都会分类为可公开、仅内部、无法支持或需验证。查不到来源的地方一律留 `[待查证]`，只有在没有任何待查证、内部备注或不可承诺的内容时，才会生成可发布的 `10-final.md`。
- **事件研判**：勾选目前观察到的情况，例如热搜、媒体跟进、投诉、安全底线。报告最前面会有：
  - 由程序算出的危机等级 I–IV（就高不就低；涉及安全、违法、未成年人或已确认的红线时，直接定为 I 级）；
  - 处置主体；
  - 风险预判；
  - 行动建议，附上可预测、可解释、可影响三轴的通过率；
  - 预案启动判定：立即启动、待命或不启动。
- **禁发模式**：未公开的内容完全不上网查询。上下文扫描的查询字符串会先列出，经你同意才发送。

本工具不构成法律意见。`src/ant_pr_review/jurisdictions/` 里的法规包只是尚未核实的起点清单；模型引用的每一条法条都会经过事实核查。

## 安装

```
uv tool install .        # 或 pipx install .
ant-pr-review            # 交互模式
```

可打印的 PDF 与 Word 版本：`uv tool install '.[export]'`（fpdf2、python-docx），并需要系统有中文字体；找不到时可用 `ANT_PR_REVIEW_FONT` 指定 .ttf、.otf 或 .ttc 文件。

JavaScript 渲染的网页：`uv tool install '.[render]'`，再执行 `playwright install chromium`。抓取失败时的顺序是：退避重试 → 无头浏览器 → AMP 版本 → 标注日期的 Wayback Machine 存档 → 请你粘贴正文。爬虫不会伪装成浏览器。

需要 Python 3.11 以上。使用 Claude 模型需要 `claude` CLI；使用其他厂商需设置对应的 key：`OPENAI_API_KEY`、`GEMINI_API_KEY`、`XAI_API_KEY`、`OPENROUTER_API_KEY`。没有任何 runtime 依赖。

## 非交互模式

```
ant-pr-review new --yes --direction outbound --jurisdictions tw,us --depth full \
  --party "竞争对手A" --embargo --target ./release.md
ant-pr-review decide <run> --yes --choice A
ant-pr-review new --yes --brief ./brief.toml --target ./内部说明.md   # 撰写模式
```

加上 `--backend fake` 可以离线试跑。设计见 `docs/DESIGN.md`；参考过的 skill 见 `docs/REFERENCES.md`；对 ant-peer-review 的评估见 `docs/EVALUATION.md`。
