# ant-pr-review

多模型、跨廠商的**公關風險審查**工具，由 Claude skill（`SKILL.md`）加上獨立的 Python CLI 組成。[English](README.md) · [简体中文](README.zh-CN.md)

可以審查三種內容：
- **對外發布**：我方要發的內容（新聞稿、聲明、貼文、廣告、KOL 腳本）
- **操作計畫**：散布或輿論操作計畫
- **被攻擊**：針對我方的內容（爆料、抹黑、負評潮）

每一種都會依法域（台灣、美國、歐盟、中國）分別評估白公關與黑公關的發布與操作風險。

- **每題都由每個模型作答的檢核清單**：固定題目分屬 10 個視角，另有各姿態與各角色專屬題目：法務、敵意記者、網路社群、被指涉方、監管與平台、內部人、揭弊者、威脅研判、回應策略。未作答的題目視為缺口，不算通過。
- **跨廠商**：可用方向鍵勾選 Claude（opus / sonnet / fable，經 `claude -p`）、OpenAI、Gemini、Grok、OpenRouter。全部來自同一家時仍可執行，但會醒目提示，因為同一廠商的模型盲點相近。
- **一個法域一組呼叫**：每個法域由各自的呼叫審查，不會一次處理多國。勾選多國時，會有一個獨立的匯整模型比較各國結果、向各國審查者提問討論，再產出匯整版報告與各國版報告。
- **兩種深度**：`quick` 是每個模型一次，加上每個法域一次；`full` 是每個視角、每個法域各一次，呼叫數約為 quick 的 4 倍。
- **判定由程式計算**：風險登記表（可能性 × 衝擊）、紅線否決（對具名對象的捏造陳述、水軍與未揭露業配、起底、選舉法規、影響股價、療效宣稱、仇恨），最後給出可發布／有條件／送審／不可發布。
- **有倫理護欄的處置方案 A/B/C**：A 是最小安全修改（字元級 diff），B 是合法替代方案，C 是應變包。護欄會移除隱匿身分或規避追溯的建議、假冒網友的留言，以及只換說法的抹黑，並標示移除了什麼。
- **姿態與手段**：姿態可選澄清道歉（預設）、廣告造勢、狙擊爆料或回應抹黑，每種姿態都有自己的檢查題；狙擊爆料限我方具名，透過不具名第三方放料屬於黑公關；手段可勾選白、灰、黑公關。不論勾選哪些手段，檢查題一律從白、灰、黑三個角度審查；勾選結果只影響報告最後的手段時間軸。時間軸列出白、灰公關的執行步驟：相對時間、當地時刻、順序、管道、注意事項、觸發與停止條件，並由另一家廠商的模型重新分類，以較嚴格的分類為準。黑公關一律不排入執行，只放進「已評估、不執行」表，說明涉及的法律、通常如何被揭穿、對手若對我方使用時的徵兆，以及合法替代做法。
- **公司概況**：提供統一編號並經你同意後，會查詢經濟部商工登記的公司資料和營業項目（不保存代表人姓名和地址），並由可搜尋的模型找出競爭對手。每家對手的來源都分 A/B/C 級，只有你勾選的才會納入審查。
- **我方角色與利害關係人地圖**：先選你在事件中的立場（涉事方、受害方、關係方），再選具體身分，例如公司本身、董事會、代言人、吹哨人；檢核清單會加上該角色專屬的題目。每個模型都會依法域，回答 7 大類（內部治理、商業鏈條、資本市場、公權力、政治與政黨、輿論、博弈勢力）各角色可能如何反應、需要什麼、我方如何處理。側翼網軍和中國黨政機構只評估、不能選為我方角色。另有 5 道角色壓力測試（法律底線、群眾情緒、內部防線、商業命脈、輿論彈藥）和 3 道政治壓力測試（彈藥、極化夾殺、主權與合規紅線），每道都要指出關鍵的那一句。
- **每個階段都有人複審，每一題都是勾選清單**：A、B、C、時間軸和黑公關排除表，都由另一家廠商的模型複審。檢核清單以勾選清單呈現，附 ASCII 通過率長條和每位審查者的判定。對外發布的內容還會附上修訂前後的 diff 與修訂後全文，並以 quick 深度重審修訂版（列出修訂前 → 修訂後）。你鎖定的句子不會被改動。
- **撰寫模式**：不審既有內容，改為回答固定問答，內容包括：
  - 事實，分已確認、被指控、未知；
  - 事件類型；
  - 受影響的人和他們最強烈的情緒；
  - 想要的結果和要做的決定；
  - 措施和各自的進度；
  - 核准人；
  - 原因與範圍是否已確認，尚未確認就只寫等候聲明；
  - 不可承認或承諾的事，例如召回；
  - 第四級旗標，例如有人受傷或已進入訴訟。

  也可以附上素材供核對事實。一個模型寫兩個做法不同的版本，另一個模型對照問答審查，每個版本再用同一套檢查矩陣各審一次。排序由程式決定，依序看是否淘汰、判定、最高風險分數、通過率；再由模型引用這些數字寫推薦理由。推薦的版本會走完整審查，最後附 diff 和修訂後全文。每個說法都會分類為可公開、僅內部、無法支持或需驗證。查不到來源的地方一律留 `[待查證]`，只有在沒有任何待查證、內部備註或不可承諾的內容時，才會產生可發布的 `10-final.md`。
- **事件研判**：勾選目前觀察到的情況，例如熱搜、媒體跟進、投訴、安全底線。報告最前面會有：
  - 由程式算出的危機等級 I–IV（就高不就低；涉及安全、違法、未成年人或已確認的紅線時，直接定為 I 級）；
  - 處置主體；
  - 風險預判；
  - 行動建議，附上可預測、可解釋、可影響三軸的通過率；
  - 預案啟動判定：立即啟動、待命或不啟動。
- **禁發模式**：未公開的內容完全不上網查詢。脈絡掃描的查詢字串會先列出，經你同意才送出。

本工具不構成法律意見。`src/ant_pr_review/jurisdictions/` 裡的法規包只是尚未查證的起點清單；模型引用的每一條法條都會經過事實查核。

## 安裝

```
uv tool install .        # 或 pipx install .
ant-pr-review            # 互動模式
```

可列印的 PDF 與 Word 版本：`uv tool install '.[export]'`（fpdf2、python-docx），並需要系統有中文字型；找不到時可用 `ANT_PR_REVIEW_FONT` 指定 .ttf、.otf 或 .ttc 檔。

JavaScript 渲染的網頁：`uv tool install '.[render]'`，再執行 `playwright install chromium`。抓取失敗時的順序是：退避重試 → 無頭瀏覽器 → AMP 版本 → 標註日期的 Wayback Machine 存檔 → 請你貼上內文。爬蟲不會偽裝成瀏覽器。

需要 Python 3.11 以上。使用 Claude 模型需要 `claude` CLI；使用其他廠商需設定對應的 key：`OPENAI_API_KEY`、`GEMINI_API_KEY`、`XAI_API_KEY`、`OPENROUTER_API_KEY`。沒有任何 runtime 相依套件。

## 非互動模式

```
ant-pr-review new --yes --direction outbound --jurisdictions tw,us --depth full \
  --party "競爭對手A" --embargo --target ./release.md
ant-pr-review decide <run> --yes --choice A
ant-pr-review new --yes --brief ./brief.toml --target ./內部說明.md   # 撰寫模式
```

加上 `--backend fake` 可以離線試跑。設計見 `docs/DESIGN.md`；參考過的 skill 見 `docs/REFERENCES.md`；對 ant-peer-review 的評估見 `docs/EVALUATION.md`。
